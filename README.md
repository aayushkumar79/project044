# PROBLEM STATEMENT 44  

This includes the frontend and backend files. Currently, the website is not deployed anywhere, so will have to follow some steps to run it.<br> 
Make the necessary folders and download all the files. Download MySQL.  
In the backend folder directory, enter cmd. 
Download all the requirements with pip install -r requirements.txt  
Write <b>python -m uvicorn main:app --reload</b> and press enter. 
In the frontend folder directory, enter cmd.  
Write <b>python -m http.server 5500</b> and press enter.  
Open: http://127.0.0.1:5500/
